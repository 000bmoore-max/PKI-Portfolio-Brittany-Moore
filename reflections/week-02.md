# Week 2 Reflection

## What did you learn this week?
This week we focused on the CIA triad and how confidentiality,  
integrity, and availability work together as the foundation  
of cybersecurity.

I learned how PKI supports these concepts by establishing  
trust between systems.

We worked with encryption and decryption, and I saw how data  
is transformed into ciphertext and then back into readable  
plaintext.

We also used OpenSSL on Windows to run commands and see how  
this works in real time.

---

## What concept was most challenging?
Honestly, nothing was too difficult, but the part that took  
a second to fully click was how digital signatures and hashing  
relate to each other.

At first it seemed like they were doing the same thing, but  
now I understand that hashing checks if data changed, while  
digital signatures also prove who the data came from.

---

## Where does this concept appear in real-world systems?
These concepts are used everywhere, especially on the internet.

Hashing is used in file verification, password storage,  
and data integrity checks.

Digital signatures are used in SSL/TLS certificates,  
software downloads, and secure websites to prove authenticity.

Encryption is used whenever data is transmitted, like when  
using HTTPS, logging into accounts, or sending sensitive  
information.

---

## How would you explain this topic to a non-technical audience?
When you send information online, encryption locks the message  
so nobody else can read it.

Hashing acts like a fingerprint to make sure nothing  
was changed.

A digital signature is like a verified stamp that proves  
who sent the message and that it hasn’t been tampered with.
