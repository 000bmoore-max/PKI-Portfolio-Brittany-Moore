# Week 01 — Key Concepts

## PKI Explanation (3–5 Sentences)

Write a clear explanation of what PKI is in your own words.

Focus on:
- The problem PKI solves
- The role of keys
- The role of certificates
- How trust is established


Public Key Infrastructure (PKI) is a system that helps secure communication on the internet by using encryption keys and digital certificates. It solves the problem of verifying identity so users know they are connecting to the correct website or system. PKI uses a public key that can be shared and a private key that must remain secret. Certificate Authorities issue certificates that link a public key to an identity. Browsers establish trust by validating the certificate chain until it reaches a trusted root certificate authority.
